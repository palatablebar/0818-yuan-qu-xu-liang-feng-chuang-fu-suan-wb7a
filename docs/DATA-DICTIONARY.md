# 字段与业务定义

输入编码 UTF-8，允许 BOM。首行必须匹配样例列顺序。记录键和业务组保留原始字符串。`kind` 允许 meter, reading, invoice。说明列 `note` 可以跨行，限制 200 字。

业务字段按 `minute`、`meter`、`kw`、`window_min`、`required` 排列。数字接受非负整数、全角数字和完整千分位。空串、短横线、N/A、NULL 与未知为缺值。无关字段用 0 占位。

minute 使用统一 UTC 时间原点。每个分表每窗接受一份读数，重复数值合并，冲突数值隔离。缺任何注册表的窗口不能参与峰值。

`incoming.csv` 包含四个业务组，第二组提供不同边界，第三组触发业务拒收，第四组需要核对。另含重复表头、冲突记录、重复回放与错误列数。`ready.csv` 含可以签发的两个组。
